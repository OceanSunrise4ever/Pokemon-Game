Pocket Quest: 1,000 Wonders 🌟

Pocket Quest is a lightweight, arcade-style Pokémon adventure built entirely in Python using Pygame. Explore the tall grass, battle wild creatures, challenge rare giant Titans, and build an ultimate collection spanning up to 1,000 unique procedurally generated species—all without needing external asset or data downloads. 

✨ Features

• Procedural 1,000 Species Roster: Combines legendary fan favorites with dynamically generated species prefixes and suffixes to provide a massive pool of catchable monsters. 

• Dynamic Evolution Mechanics: Level up your partner to trigger evolutions at custom level milestones (e.g., Bulbasaur evolving into Ivysaur, then Venusaur). 

• Intense Titan Boss Battles: Every 5 captures triggers a formidable Boss encounter against giant variants like Titan Mewtwo or Titan Charizard. 

• Vector Graphics Engine: Renders clean, modern shapes and animations using pure geometric code—eliminating the need to package bulky image assets. 

• Turn-Based Battle System: Pick your strategy from an 8-slot move library featuring damage variants, high-risk mystic strikes, and utility heals. 

🛠️ Installation & Setup


Prerequisites

Make sure you have Python 3 installed on your machine.

1. Clone the Repository

bash
git clone https://github.com

cd pocket-quest

2. Install Dependencies

Pocket Quest relies exclusively on pygame: 
bash
python -m pip install pygame

3. Run the Game

Execute the main file to boot up the title screen: 

bash

python "Pokemon game.py"

🎮 How to Play & Controls


🏢 Title Screen

• Keys 1 to 6: Select your starting partner from the roster (Bulbasaur, Charmander, Squirtle, Pikachu, Eevee, or Ralts) and launch the journey. 

🌲 Exploration Mode

• WASD or Arrow Keys: Navigate your hero around the camp map.
• Tall Grass: Walk into the central fields to roll random encounters and trigger wild battles.
• Key R: Rest at the base camp to instantly restore your partner's health.
• SPACEBAR: Clear victory banners and resume hunting. 

⚔️ Battle Arena

• Keys 1 to 8: Activate your moves during the player turn.
• SPACEBAR: Pass the turn to the opponent to resolve their counter-attack sequence.
